# ADR 0003. Локальный AI для поиска и пост-обработки

## Статус

Принято.

## Контекст

TheCocktailDB поддерживает только один фильтр за запрос и не содержит полей, которые
есть в UI (вкус, цвет, навык, газированность). Пользователю нужен естественно-языковой
поиск и пост-обработка рецептов (перевод, разделение количества и единиц измерения).
В окружении доступен локальный LLM-сервер с `gpt-oss:20b`.

## Решение

Встроить AI через **OpenAI-совместимый** локальный endpoint:

- `POST {AI_BASE_URL}chat/completions`, конфигурация через `BuildConfig`
  (`AI_BASE_URL`, `AI_MODEL`, `AI_API_KEY`), значения по умолчанию —
  `http://10.0.2.2:11434/v1/` и `gpt-oss:20b`;
- **AI-поиск**: `AiSearchPlanner` отправляет описание + текущие UI-фильтры и просит
  JSON-план с 1–3 комплементарными запросами TheCocktailDB (name/ingredient/glass/
  category/alcoholic). Ответ парсится в `SearchRequest`, репозиторий выполняет запросы и
  объединяет результаты по `idDrink`; при неудаче используется исходный фильтр;
- **пост-обработка**: `AiTranslator` переводит инструкции на язык приложения (с
  эвристическим пропуском, если язык уже верный); `MeasureParser` детерминированно
  разделяет количество и единицу по списку допустимых единиц приложения;
- системные промпты адаптированы из официальных `AGENTS.md`/`SKILL.md` TheCocktailDB
  (только официальный API, не выдумывать данные, не заявлять об исчерпывающем результате);
- AI-вызовы не блокируют основной сценарий: при недоступности сервера показывается
  ошибка, прямой поиск и локальные данные работают.

## Последствия

- Появляется зависимость от локального сервера и его задержки (20B-модель может отвечать
  десятки секунд).
- Для локального HTTP включён `usesCleartextTraffic`; для production нужен HTTPS или
  доверенная локальная сеть.
- `Alcoholic`-переключатель в UI по умолчанию `true` и не должен перетягивать AI-план:
  промпт отдаёт приоритет естественно-языковому запросу.
- Качество поиска зависит от модели; план валидируется и имеет fallback.
- Разбор единиц сделан детерминированно (надёжнее LLM), AI отвечает за перевод.
